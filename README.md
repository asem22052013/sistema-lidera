# «Система Лидера»: бот-наставник и материалы проекта

Реализация PRD v1 от 03.10.2026.

## Что внутри

```
bot/                 бот-наставник (Python, aiogram 3, SQLite)
  program.py         30 заданий программы, тексты и ссылки на видео редактируются здесь
  texts.py           все остальные тексты бота
  scheduler.py       9:00 задание · 20:00 напоминание · 3 дня тишины → наставник · контакты · рейтинг
  handlers/          onboarding, newbie, team, contacts, admin, common
content/
  channel.md         описание канала, закреп, ритм, чек-лист перед публикацией
  club.md            настройка PRO-группы, темы и закрепы, тарифы, выдача доступа
  marathon21.md      модуль 5: марафон на 21 день
tests/               тесты логики и сквозного сценария (без Telegram)
```

## Требования PRD к боту: что сделано

| № | Требование | Где |
|---|---|---|
| B1 | /start, выбор роли | `handlers/onboarding.py` |
| B2 | Цель + наставник → старт «30 дней» | `onboarding.py`. Наставник подставляется по ссылке-приглашению или по @username |
| B3 | Задание в 9:00 (текст + видео) | `scheduler.py`, `program.py` |
| B4 | «Выполнено» и «День N из 30» | `handlers/newbie.py` |
| B5 | Напоминание в 20:00 | `scheduler.py` |
| B6 | 3 дня без отметок → наставнику | `scheduler.py`. Сообщение уходит и наставнику, и новичку: «Давай упростим» |
| B7 | /team: команда, день, активность | `handlers/team.py`, вся структура вглубь, лимит «5 новичков на наставника» |
| B8 | «Мои контакты» + напоминания | `handlers/contacts.py` |
| B9 | День 30 → «Выпускник», предложение стать наставником | `services.complete_day` |
| B10 | Рейтинг недели | /rating + автоматически по понедельникам в 10:00 |
| B11 | Оплата в боте | v1.1. Сейчас админ вручную выполняет `/grant` и `/revoke` (см. `content/club.md`) |
| B12 | ИИ-помощник | v2, не делалось |

Нефункциональные требования:
- **Время.** По умолчанию UTC+5, у каждого пользователя свой пояс через /tz. Часы рассылок настраиваются в `.env`.
- **Персональные данные.** Согласие спрашивается до сохранения любых данных. Есть /privacy и /delete_me (полное удаление).
- **Без медицинских советов.** На вопросы о здоровье бот отвечает дисклеймером. Тексты заданий проверяет тест на стоп-слова.

Логика программы:
- Следующее задание приходит утром только после того, как отмечено предыдущее. Пропущенный день не «сгорает»: утром бот напомнит то же задание.
- Если бот был выключен в 9:00, задание уйдёт сразу после запуска. Повторно оно не придёт.

## Команды
Все: `/start`, `/task`, `/progress`, `/contacts`, `/tz`, `/privacy`, `/delete_me`, слово **ПЛАН**.
Партнёры и лидеры: `/team`, `/rating`, `/link`.
Админы (`ADMIN_IDS`): `/stats` (метрики PRD: активные через 30 дней, выполнение заданий, выпускники, наставники), `/grant`, `/revoke`.

## Запуск
Нужен Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

В `.env` впишите `BOT_TOKEN` (получить у @BotFather) и свой Telegram ID в `ADMIN_IDS`. Затем:

```bash
python -m bot
```

Тесты:

```bash
pytest
```

Для работы 24/7 бот нужно запустить на сервере (VPS) как службу. Пилоту на 20 человек хватит самого дешёвого VPS. База — один файл `data/bot.sqlite3`, его достаточно регулярно копировать.

## Порядок запуска пилота
1. Лидер и 3–5 наставников нажимают /start → «Партнёр» или «Лидер» и получают свои ссылки-приглашения.
2. Наставники раздают ссылки новичкам. Новички закрепляются за наставником автоматически.
3. Добавьте ссылки на видео в `bot/program.py` (поле `video`) по мере съёмки.
4. Раз в неделю на планёрке смотрите `/team` и `/stats`.

## Перед запуском (раздел 11 PRD, вне кода)
- Политика обработки ПД и оферта: опубликовать и вписать ссылку в `PRIVACY_URL`.
- Показать тексты заданий, канала и марафона юристу.
- Решить открытые вопросы PRD: род в текстах (сейчас «сделал(а)»), сервис оплаты (для B11).
